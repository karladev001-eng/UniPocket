# 静大ポケット — PWAとSwift版

今後のURL配布用に独立したPWAを `web/` へ追加しました。ホーム / 時間割 / 記事 / メモ / その他の5画面を備え、掲示板は表示しません。ブラウザごとの空の個人データから始め、既存Swift版のファイルや保存データは変更しません。

Node.js 22.18以上で、リポジトリ内の `web/` を実行ディレクトリにします。

```sh
npm ci
npm run typecheck
npm run test:all
npm run test:integration
npm run db:local
npm run local
```

`http://127.0.0.1:8787` でPWA本体とWorker APIが同じoriginで動きます。`test:integration` が本体をビルドし、一時D1で結合を検証します。通常は `npm run build` でもビルドできます。`local` / `db:local` は明示したpreview環境のローカルDBを使い、Cloudflare認証は不要です。Viteの静的previewだけでは記事APIは動作しません。

時間割・PDF差分・メモと画像・施設とリンク・地図・テーマと背景は端末内に保存します。Notion記事は公開URLと一覧情報を共有DBへ登録し、本文はNotionで表示します。匿名ユーザーのCookieで投稿編集とブックマークを管理します。外部カレンダー連携と旧Swiftデータの自動移行は初回対象外です。端末内データやPDFは記事サーバーへ送信しません。

本体の更新は通知後に利用者が操作し、開いているタブの入力保存を確認して適用します。記事API・認証応答はオフラインキャッシュへ入れません。保存・匿名権限の制約、PDF対応範囲と更新動作は [Webクライアント説明](web/CLIENT.md)、Cloudflareのpreview/production分離、D1 migration、公開・バックアップ・ロールバック手順は [配信手順](web/DEPLOY.md) にあります。

Cloudflareの本番アカウント・実DB・公開URLは未接続です。実Android/iPhoneの導入・更新、実際の対象Notionページの埋め込み、実PDFの取込、クラウド上のバックアップ復元は未確認です。公開サンプルのトップレベル表示だけを埋め込み成功とは扱いません。設定内の仮DB IDを実IDへ置換し、配信手順の実環境確認を終えてから配布してください。

## Swift版の説明と既存検証記録

静岡大学・浜松キャンパス用のiPhoneアプリです。iOS 17以上、SwiftUI / PDFKit / EventKit。PDF・メモ・画像・施設時間・リンクを端末内に保存します。サーバー、Microsoft Graph、外部AI、独自iCloud同期はありません。

## 起動・iPhoneへの導入

1. `CampusPocket.xcodeproj`をXcodeで開き、共有scheme `CampusPocket`を選びます。同梱の`CampusCore`はローカルSwift Packageです。
2. Simulatorで実行できます。実機へ入れる場合はXcodeのApple Account / Signing設定と、iPhoneの開発者モードを本人が設定してください。実機署名やアカウント設定は自動では行いません。
3. ホームの「PDFから予定を取り込む」でFiles内の履修登録確認票と年間行事予定表を選び、差分プレビューを確認して保存します。

## 画面と操作

- **共通デザインと入口**：ホーム / 時間割 / 掲示板 / メモ / その他の5タブ。掲示板の上部で「投稿 / 記事」を切り替えます。施設・リンク・PDF取込・科目修正・設定は「その他」に集約しています。green / blue / rose / mono の配色を端末内保存し、補助画面と編集シートにも適用します。
- **掲示板**：初回はキャンパス全体の操作見本を開き、通常のタブ移動は最後の講義・投稿/記事の選択を保持します。保存された講義の詳細からは正確な講義名・IDの掲示板を開きます。実際の講義は投稿なしから始まり、全体の投稿・人物・反応数はサンプルです。投稿・返信・匿名選択・タグ・画像添付・端末内圧縮を試せます。投稿や下書きは同じ起動セッション内で講義ごとに保持しますが、アプリ終了やWeb画面の終了で消えます。外部送信・公開サーバー・認証・永続保存はありません。画面上部にも操作デモの制約を常時表示します。「授業に戻る」で元の詳細へ戻れます。
- **週間カード**：平日5列・1〜5コマの一覧を既定表示。コマの表示は取り込んだ時刻と完全一致する講義のみで、変更した時刻は推測しません。土日、6〜7コマ、外部・終日・短時間は件数付きの日別一覧へ進めます。重複したコマは全件一覧を開き、日・月表示と個人修正を維持します。大きい文字では日別一覧に切り替えます。
- **ホーム**：今日と次の授業、開始・終了・教室、開始/終了までの時間、端末Outlook予定、同じ計算結果による施設時間。カード下の「すぐメモ」で本文編集に直接進めます。固定メモの先頭画像を表示し、拡大・並べ替え・固定解除できます。
- **キャンパスマップ**：ホームをスクロールすると地図をそのまま操作できます。ホーム/予定一覧/選択カード/詳細/科目一覧の場所をタップすると、ホーム内の同じ地図へ移動します。既知の教室・建物名から対応する建物を琥珀色で強調し、予定の元の場所と正式名称を表示します。地図と34施設を同梱し、通信なしで表示できます。ピンチとボタンで拡縮し、拡大中は地図を移動できます。全体表示ではホームを上下にスクロールできます。全体復帰と、ホーム内で展開する建物一覧/検索に対応します。空欄・オンライン・未登録・複数候補の場所は自動選択せず、一覧から選べます。手動選択はその旨を表示します。提供構内図は2026-04-01現在の北が上の概略図で、施設503/901は輪郭がないため位置の目印を表示します。館内図・階・経路案内は含みません。
- **日・月表示**：日表示では設定した時間範囲の連続時間軸と全件一覧を併記します。短時間・重複した予定は日別全件を開けます。月表示は日付を選ぶと当日の一覧を更新し、時刻・教室・正式名を確認できます。
- **授業の個人修正**：予定詳細から1回/科目全体の名前・教室・時間・休講を変更し、解除できます。科目全体の時間変更は元の日付を維持して開始時刻と長さを適用します。科目一覧から時間未定の研究・セミナーに個別日程を追加できます。科目一覧には取消し済みと追加した回も残します。
- **施設**：通常曜日ごとの区間、昼夜、L.O.、確認日と出典を保存。日付例外は通常時間より優先し、空欄で休業、解除で通常時間に戻します。営業時間は通常期の目安です。初期値の確認日は2026-10-07で、今回最新取得したものではありません。祝日や休講期間は公式案内を確認してください。旧版の解析できない自由文は未確認として原文を表示します。
- **メモ**：専用タブの2列カード（アクセシビリティ文字サイズでは1列）、本文/チェック項目検索、固定セクション。本文の先頭行がタイトルとなり、本文・チェック項目・完了状態・淡い背景色を自動保存します。本文だけのメモもホームに固定できます。新規の未入力メモは閉じると取り除き、既存の空メモは保持します。写真選択/FilesからJPEG・PNG・HEIC静止画像を複数保存し、並べ替え・添付削除・ピンチ拡大/移動できます。画像だけでも保存・固定可能。40MB、各辺20,000pxを上限として原寸ファイルを保存し、黙って縮小しません。取得中は取消可能。クラウド写真は通信が必要な場合があります。失敗時は本文と既存画像を保ち、再試行できます。
- **メモ削除**：画像削除は確認画面を表示し、添付削除・メモ削除とも同じ起動セッションの30秒以内は取消できます。固定解除は原本を消しません。メモ削除で固定参照を解消します。取消しのため参照を外した画像ファイルを保持するため、保存領域の即時解放は行いません。
- **リンク**：追加・編集・削除・Editによる並べ替え・お気に入り。Webには通信が必要です。http(s)のみ、URL中の認証情報は保存できません。

## PDFと再取り込み

初回対象は既知の後期の履修登録確認票と通常課程の年間行事予定表です。年度、学期、ページ、表位置と授業回を検証します。前期・未知形式・画像だけのPDF/OCRは対象外です。氏名・学籍番号・単位表・原本PDFは保存しません。原本は端末内で解析するだけです。

実物の2026後期PDFで4通常科目、2時間未定、56授業＋4試験候補を確認します。11/25の月曜授業、11/6浜松休講、1/7の対面授業等なし、年越しを適用し、夜間主コースを混ぜません。試験・第15回は候補ラベルを表示します。

原本由来の予定と個人修正は別保存です。同じPDFの再取り込みで件数は増えません。追加・変更・削除の差分を表示し、個人修正がある回は「個人修正と旧原本を保持」か「この回に新PDFを採用」を選ぶまで保存できません。1回へのPDF採用がほかの回の個人修正を消さないよう、必要なら科目修正を回別に分けます。保存失敗・解析失敗・取消しでは保存済みの原本を維持します。

## Outlookは表示のみ

iPhone標準カレンダーにExchange / Outlookを追加して同期を有効にする必要があります。Outlookアプリだけのログインでは接続されません。大学アカウントを標準カレンダーで利用できるかは、ユーザー端末で未確認です。

読み取りに必要なEventKitフルアクセスを要求し、選択したカレンダーを中心日±40日から取得します。未許可・拒否/取消し・対象なし・未選択と、取得済みを区別します。取得範囲・端末取得時刻を設定に表示し、最新のOutlook同期は未確認であることを示します。外部予定はメモリ内だけに置き、独自の永続コピーを保存しません。

外部予定の追加・変更・削除APIと書き出しUIはありません。以前の書き出しURL `campuspocket://event/<id>` がローカル原本のIDと正確に対応する時だけ旧外部コピーを非表示にし、現在のローカル修正を表示します。名前や時刻が同じ一般の予定を隠しません。取消し済みのローカル回も旧外部コピーによって復活しません。

## 保存・移行

Application Support / CampusPocket / `data.json`と`Images/`に保存します。JSONと画像は原子的書き込み。画像ファイル保存後にメモ参照を保存し、参照の保存に失敗すれば追加ファイルを撤回します。欠損画像は警告を表示し、本文を保持します。

メモの色・チェック項目がない旧データは無色・空リストで読み込み、既存ID・本文・画像・固定順序を維持します。

schema=1は元のバイト列を内部`data.json.schema1-original`へ退避してからschema=2へ移行します。破損・未知schema・退避/移行保存の失敗では原本を上書きせず、読込できなければ編集を止めます。これは内部移行保護で、ユーザー向けバックアップ画面ではありません。通常の本文保存失敗は変更を画面に残し「保存失敗」と再保存を表示します。アプリ終了前に再保存してください。アプリ削除でローカルデータは失われます。

### 記事と下書き

下部「掲示板」の「記事」と授業詳細の「関連する記事」から、同梱した7件の架空の記事を読めます。実際の講義にはサンプルを推測で紐付けず、該当なしの案内から全記事に進みます。カテゴリと検索、関連記事、画面内だけの反応に対応し、既存の予定・地図・施設・メモ・リンクを維持しています。全画面共通の4テーマは「その他 → テーマ・背景」から選び、再起動後も保持します。旧記事テーマの選択値も引き継ぎます。

一覧のペンから、記事と同じ紙面で下書きを書けます。`# `、`## `、`> `、`- `、`1. `などは半角スペースまで入力すると書式に反映します。`-`だけでは箇条書きになりません。Markdown全文の入力・コピーは小さなアイコンから開き、画像・HTTP(S)リンクは補助メニューから追加します。画像の添付参照はその下書き内で有効で、Markdownコピーは画像ファイルの書き出しではありません。

記事一覧・講義からの入口は単一のWebViewと下書きセッションを共有します。投稿/記事や下部タブの切替でも両セッションの入力を保持します。講義からの明示移動は両セクションに同じ講義文脈を渡し、どちらからも元の講義へ戻れます。講義を切り替えても古い本文を再読込せず、保存失敗・未確定入力は保持します。「授業に戻る」で元の授業詳細へ戻れます。下書きは1件をこのiPhoneの `Application Support/CampusPocket/Articles/draft.json` に自動保存します。本文と全添付実体を同じファイルに原子的に書き込み、保存失敗時は画面の編集と元ファイルを保ちます。読み込みに失敗すると自動上書きを止め、明示的な再保存時も元ファイルを回復用に保管します。保存完了前の戻る操作は待機または案内し、画像処理・IME中の移動やテーマ変更で未確定の本文を捨てないようにしています。記事下書きは予定/メモの `data.json` と画像保存領域とは別に保管します。公開・外部送信・クラウド同期はありません。

画像はJPEG/PNG/WebP、1枚20MiB・24MP、表紙1枚・本文8枚・合計40MiBまで。長辺2048px・WebP品質0.82（PNGへのフォールバック、小さい原本優先）で端末内処理します。外部画像URLは自動取得せず案内だけ表示し、リンクは利用者が操作したHTTP(S)だけを端末のブラウザーで開きます。デスクトップのブラウザー下書きは自動移行できないため、Markdownを明示的にコピー/貼り付けしてください。

検証コマンド: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer scripts/test-core.sh` と `node scripts/test-articles.cjs`。Coreテストは原子的保存、画像/本文復元、読み込み失敗時の保護、古いrevisionの拒否、最大40MiB画像+50万codepointsのarchive上限を確認します。NodeテストはDOM/Selectionとnative bridgeのスタブで書式反応・IME確定・編集中テーマ変更・保存競合/失敗/初期復元・画像変換を検証します。実機のIME/Undo/選択や写真ピッカー全経路は別途確認が必要です。iOS27 Simulatorではホーム入口・一覧・執筆面・入力した非空本文の実ファイル保存・空下書きの戻る/再開を確認済みですが、Device Hubの入力モードとクリップボード同期の制約により、指定した半角Markdown文字列での実入力確認と、非空本文を再起動後に実画面で復元する確認は未完了です。


「その他 → テーマ・背景」で、写真またはファイルのJPEG・PNG・HEIC静止画を選び、プレビュー後に適用できます。初期状態は配色に応じた無地です。背景は5タブで共有し、カード・ラベル・記事の本文と執筆用紙・地図・画像ビューアは読みやすい専用面を保ちます。画像の選択・処理は取消可能で、連続選択では最後の画像だけをプレビューします。「この画像を使う」で保存し、「無地に戻す」で解除します。入力は40MiB・各辺20,000px以下、表示用は向きを補正して長辺2,560px以下へ縮小します。元写真は変更せず、外部送信しません。

背景は `Application Support/CampusPocket/Appearance/background.jpg` に原子的保存し、予定とメモの `data.json` や記事下書きに含めません。読込・変換・保存は画面スレッドの外で直列に処理し、表示用画像を各タブで共有します。WebViewへ渡すのは背景の有無だけです。選択取消・変換/保存失敗では適用済みの背景を保ち、保存画像の欠損/破損は無地で表示して設定画面に案内します。適用ボタン後の原子的保存中は背景操作を一時停止します。背景の読込・縮小・向き・透過PNG・入力上限・失敗保存と再試行はCoreテストで確認しています。HEICはテスト環境にある静止画を実際にデコードして確認し、ファイルのない環境ではその項目のみ案内を出します。写真ピッカー/実機・連続選択・アプリ再起動の実操作は別途確認が必要です。

# 静大ポケット Webクライアント

Swift版を変更せず、ブラウザごとの新規データから始める独立PWAです。架空の記事・時間割・メモは配信しません。施設の通常期時刻とリンク、地図はSwift版の同梱情報を移植しています。営業時間は更新日のある目安で、公式案内で確認してください。

## ローカル

Node 22.13以上で `npm ci`、`npm run build`、`npm run preview`。開発時は `npm run dev`。APIは同一オリジン `/api/*` で、Vite開発サーバーは127.0.0.1:8787へプロキシします。Worker/D1の起動と配信はDEPLOY.mdを参照。静的previewだけでは共有記事APIは動作しません。

- `npm run typecheck`
- `npm test` — 個人修正・PDF差分、PDF座標パーサー、IndexedDB原本保護と複数タブ競合、SW更新プロトコル
- `npm run test:server` / `npm run test:runtime` — API担当のNodeテスト（統合後）

## 端末内データ

`shizudai-pocket` IndexedDBのv1 `state` ストアに保存します。読み込めないデータはデフォルトで上書きしません。保存はトランザクション＋revision照合で、他タブの保存を検出した場合は入力を画面に保持して書込を拒否します。「その他→入力データを書き出す」で現在の入力を退避して再読み込みできます。画像と背景はブラウザでJPEGに縮小変換し、メモ・PDF原本を記事APIへ送りません。PDF原本は保存せず解析結果だけを保存します。

メモと記事下書きは入力時に自動保存。予定フォームも下書きを保存し、更新/再起動後に再開します。施設・リンクの編集は保存ボタンで確定し、編集画面を開いている間は更新適用を止めます。ブラウザの容量不足・保存拒否・別タブ競合時には未保存を明示します。OSによるサイトデータ消去やプライベートブラウズ終了後の復元は保証できません。

既知の通常課程の後期登録票/年間行事予定表だけが対象です。座標・縦横比・年度・全15回を検証してから差分確認へ進みます。PDF.jsのCMap・標準フォント・WASMを同梱しオフラインでも解析できます。前期・画像のみ・OCR・未知形式を推測して取り込みません。個人修正と原本差分が競合した際は選択を必須とし、講義全体の修正から1回だけPDFを採用する場合は他の回の個人修正を保持します。

## 更新

ビルド時刻とランダム識別子をbuild IDとして `/version.json` に更新内容とともに出力します。`BUILD_ID` でリリースIDを明示指定することもできます。現在表示中のビルドIDと配信中のビルド情報を区別して表示します。全シェル・PDF資材・地図を取得できたSWだけがwaitingに進みます。起動/オンライン復帰/前面復帰時は1時間を上限に確認し、設定から手動確認できます。新SWの適用は利用者の「保存して更新」操作後、全タブに保存要求→全タブの成功→skipWaiting→controllerchangeによる1回の再読み込みです。IME/画像処理/PDF解析/送信中、保存失敗や応答しないタブでは有効化しません。期限切れの待機は解除し、入力を保持します。

API・セッション・POSTはSWキャッシュに入れません。インストール済みのHTMLを返し、更新前の古いタブのアセットキャッシュも削除しません。互換性を優先し旧版キャッシュは自動削除しないため、長期運用で容量監視と安全な世代整理の設計が必要です。IndexedDBと匿名Cookieは更新で消しません。

## Notionと匿名ユーザー

公開URLを勝手にiframe URLへ変換しません。Notion公式の埋め込みコードからsrcだけを抽出・検証します。公式埋め込みURLがなければ元ページで読む案内を表示します。iframe loadで成功と断定せず、元ページ・再読み込み操作を常設します。HTMLコード自体は実行しません。

初回の匿名セッション確立はWeb Locksでタブ間直列化し、ロック内でGET再確認→必要時POSTします。Web Locks非対応時は専用IndexedDBストアの期限付きロックで同じ処理を行います。記事の閲覧記録前も同じ準備を行います。公開情報の所有者判定と集計はAPIが返す値を表示し、クライアントから所有者IDや集計値を送信しません。

## 未検証・実環境の受入

自動テストのPDFは既知座標を再現したテキストfixtureです。本人の実登録票/年間行事PDFを用いたPDF.js文字座標の照合、Android Chrome/iPhone Safari実機のインストール・更新・HEIC、実Notion公式埋め込み、Cloudflare本番接続・配信は別途必要です。本番アカウントやユーザーの公開Notion URLはこの実装時点で未提供です。モックや静的previewをこれらの合格扱いにしません。

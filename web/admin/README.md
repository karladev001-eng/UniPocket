# Uni Pocket 管理画面

この入口は一般アプリと別originで配信する管理Worker用です。`/api/admin/me`で管理者を確認してからデータを取得します。認証切れや通信失敗では編集中の入力を画面に保持し、利用者の操作で別タブのログインと認証再確認へ進みます。編集中の内容や回答を端末ストレージへ保存しません。

`web`で実行します。

```sh
npm run typecheck:admin
npm run test:admin
npm run build:admin
```

出力は`web/dist-admin`です。公開用の`build`とは分かれており、一般アプリのアセットは取り込みません。管理画面にはオフライン機能を作りません。管理Workerで全パスのAccess保護、JWT検証、private/no-storeヘッダーとCSPを適用する必要があります。

ローカルの製品確認は管理APIを`127.0.0.1:8788`で起動し、`npm run dev:admin`（`127.0.0.1:5174`）を使います。ViteのAPI proxyだけでは管理者認証は通りません。バックエンドのfail-closed認証を維持したまま、テスト用署名・所有者設定を備えた環境で確認します。本番用の認証回避スイッチはありません。

日付の編集は日本時間、APIはUTC ISO8601、日次集計キーは日本時間の日付です。公開済みアンケートの設問は編集せず、複製時に設問・選択肢をすべて新IDにします。CSVは管理APIから別操作で取得し、画面側で回答や集計を捏造しません。

記事は題名・投稿者・カテゴリの検索語と公開状態をサーバーに送り、通報も確認状態をサーバーで絞り込みます。50件ずつcursorで追加取得し、古い検索応答は表示へ反映しません。通報対象は一覧へ読み込まれている範囲に依存せず単体取得します。非表示・再公開は確認した対象ID・revision・理由と同じIdempotency-Keyで再試行します。

単体テストは認証の境界、入力保持・重複再試行、日時・期間・設問制約、DOMのテキスト出力と表の意味を検証します。実ブラウザの寸法・キーボード・Cloudflare Access・実D1の検証は統合時に別途必要です。

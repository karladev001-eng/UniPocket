## 修正必須の指摘

### R1 / P2 — 別月閲覧後、ホームが今日の外部予定を欠落扱いにする

位置: `CampusPocket/CampusPocketApp.swift:50`、`CampusPocket/CalendarModel.swift:60`（関連 `:81`）、`CampusPocket/AgendaView.swift:117`。

標準カレンダーに今日の予定があり選択済みの状態で、予定タブから今日より40日以上離れた日付へ移動し、ホームへ戻る。CalendarModelは最後の選択日を中心に-40/+41日だけ取得し、Homeはその配列から今日を抽出する。ホーム出現時の今日への取得処理がなく、フォアグラウンド復帰も最後のfocusで再取得する。今日の外部予定が取得範囲から外れたまま、ホームは「保存された今日の予定はありません」と「端末から取得済み」を示す。AC1/S3/AC5の未取得と予定なしの区別を満たさない。

ホーム表示時に今日の範囲を確保し、取得範囲にない日を予定なしと表示しないこと。独立テストはEventKit実アカウントを使用していないが、範囲と遷移のコード経路が確定している。

### R2 / P2 — 深夜を跨ぐ時間外予定の件数がゼロになる

位置: `CampusPocket/AgendaView.swift:146`。

例: 今日20:00〜翌日09:00の終日でない外部予定。今日のitemsには入るが、時計の分だけを比べるextra判定は `20:00 < 08:00 == false`、`09:00 > 19:00 == false` で件数ゼロ。今日のtimed交差判定には入らないためグリッドにも表示されず、時間外予定の存在を示す件数が失われる。昨日16:00〜今日07:00も同様。AC2/S1の時間外件数からの全件到達に欠陥。

表示日の開始/終了Dateに対し予定区間を比較して集計すること。日をタップすれば一覧には残るためデータ消失ではないが、存在を伝える表示が欠ける。

### R3 / P2 — 施設帯をタップした日の詳細を表示しない

位置: `CampusPocket/AgendaView.swift:175`（関連 `:116`）、`CampusPocket/PersonalViews.swift:40`。

未来の日付に個人例外を保存し、その日の営業時間帯をタップする。タップは施設UUIDだけを保持してFacilityEditorを開き、詳細の計算結果も例外日付の初期値もDate()になる。帯に表示した未来の日の臨時時間・例外を直接確認できず、今日の通常時間を表示する。S1の「帯をタップした詳細に施設名・開始終了・確認日・例外」とAC7の一貫性を満たさない。

施設IDとタップ対象日を渡し、その日の区間と個人設定を詳細に表示すること。

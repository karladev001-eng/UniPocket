今回の変更

ホームと予定を統合し、下部を「ホーム・施設・メモ・リンク」の4タブにする。起動すると時間割が開き、次の授業を同じ画面で確認できる。

一番下のカードは、普段は次の授業、予定を選ぶとその詳細に切り替わる。営業時間と固定画像は、ホーム上部の「キャンパス」から展開する。メモは引き続き1操作。

段階：この案を確認 → 承認後に画面を統合 → 小画面・既存機能を検証。PDF解析、保存形式、Outlookの連携方式は今回の変更対象外。

Q8回答済み：初期表示は週の時間割。掲載モックと同じ方針で確定しました。実装承認は別です。仕様・承認の正本

ホームを開くだけで、時間割と次の授業を確認できる。

見やすさは、余白・色・選択カードを整理して改善する。

  • 大きなタイトルと重複する日付行を省き、時間割へ場所を渡す。
  • 授業は淡い青の面＋濃い文字。外部予定は紫と記号。今日の列は薄い青、土日は淡いグレー。
  • 08–19時の等間隔軸、2時間ごとの線、開始/終了は維持。施設の帯は端に寄せ、授業の文字を遮らない。
  • 短縮名は枠内、正式名・教室は下のカードへ。選択後も次の授業へ戻れる。
  • 7列で文字を無理に縮小せず、短い予定・重複・時間外は件数から全件一覧へ。

週・月・日、固定画像、未取込、文字拡大の状態を確認する。

営業時間・固定画像・お気に入りは、ホーム内のキャンパスパネルにまとめる。

常設の大きな画像カードを時間割の下に並べると、週の1画面表示と競合するため、ホーム上部から開くパネルへ移す提案。固定・並べ替え・固定解除・画像拡大は維持する。

すぐメモは直接、PDF取込と科目管理はメニューから開ける。

  • 上部の「メモ」：空のメモを開き、キーボードを表示。
  • 「キャンパス」：今日の営業時間、固定メモ、画像、お気に入り。
  • 「⋯」：PDF取込、科目と個人修正、表示範囲と外部カレンダー設定。
  • 旧「すべての予定」は統合後に不要。施設/リンクへの移動先も4タブに合わせる。

統合で、保存済みの予定・メモ・画像を失わない。

  • schemaの変更やデータの再取込を要求しない。端末内のデータと選択した外部カレンダーを使用。
  • 今日と閲覧中の週/月が違う時も、今日の次の予定と表示期間の予定を両方取得。未取得を予定なしと表示しない。
  • 毎分・復帰・日付変更で現在線と残り時間を更新。別週に現在線を出さない。
  • Outlookは表示のみ。再取込/個人修正/施設例外/画像取消しの動作はv4を維持。
  • 文字拡大は日別一覧へ。保存エラーはバナーで伝え、画面が狭い場合は一覧表示へ切替可能。

既存のHomeViewとAgendaViewを組み合わせ、タブと取得範囲を揃える。

選択カードを、次の授業と選択した予定の両方に使う。

表示中の期間と、今日のサマリーを別の状態として持つ。

PDF対応形式や同期方法の拡張は行わない。

  • Outlookへの書込・直接Microsoft連携、通知・ウィジェットは対象外。
  • 施設時間の自動更新、画像の自動取得、新しい保存形式は対象外。
  • v4の未確認項目（実機接続等）は引き続き未確認として扱う。

番号付き受入条件

  1. AC13：4タブになり、ホームで週/月/日と次の授業を確認できる。関連 統合。
  2. AC14：標準文字の375×667pt以上で週7日・08–19時・カード・タブが1画面に収まり、開始終了が読める。短時間・重複・範囲外も全件へ到達。関連 視認性。
  3. AC15：メモ1操作、PDF・科目管理・設定・施設・リンクへ到達。固定画像の拡大/並び/解除を維持。関連 キャンパス。
  4. AC16：別週閲覧・日付変更・復帰・未許可でも今日の状態を誤表示しない。関連 取得と状態。
  5. AC17：保存データ、PDF再取込、修正、施設例外、画像と外部予定の読み取り専用を維持。関連 維持。
  6. AC18：小画面・ダーク・文字拡大・VoiceOverのラベル/順序・起動・詳細からの復帰を検証。主要4タブの誤遷移なし。関連 各状態。

既存AC1–AC12は第5版の変更箇所だけ読み替え、それ以外を維持する。

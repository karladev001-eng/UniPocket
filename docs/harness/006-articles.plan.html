Markdownの入力ルール

記事面へ直接入力します。Markdown全文画面では、記法をそのまま編集できます。

記法反映するタイミング結果
# 〜###### 行頭の記号の後に半角スペース見出し
> 行頭で半角スペースまで入力引用
- / * / + 行頭で半角スペースまで入力箇条書き
1. 行頭の数字とピリオドの後に半角スペース番号付きリスト
**太字** / *斜体*閉じ記号まで入力強調表示
`コード`閉じバッククォートまで入力インラインコード
[表示名](https://example.com)有効なHTTP/HTTPSのURLと閉じ括弧まで入力リンク
行頭のバッククォート3個Enterで開始／閉じフェンス＋Enterで終了コード欄
複数行のMarkdownを貼付け貼付け後（IME変換中は確定後）見出し・引用・リストなどへ反映

- だけは普通の文字です。- の後に半角スペースを入れると箇条書きになります。未完成の記法、明示的にエスケープした記号、コード内の記号は書式へ変換しません。

見出し末尾のEnterは次の段落へ。リストのEnterは次の項目へ、空の項目でEnterすると通常の段落に戻ります。日本語変換中は表示を作り直さず、確定後に反映します。

画面内での入力・貼付け・Enter・日本語確定を検証対象にします。下書き保存・コピーでもMarkdown原文を保ちます。

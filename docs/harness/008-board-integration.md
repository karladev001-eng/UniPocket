## 仕様と受入条件

- C1: 下部に「掲示板」を追加し、ホーム/時間割/掲示板/記事/その他へ進める。既存タブ・メモ等を失わない。共通4テーマを適用。
- C2: 保存された講義の詳細から「この講義の掲示板」へ移動する。講義名/IDを正確に扱い、架空講義に代替しない。ホーム詳細と日一覧sheetを含め、戻ると元の詳細へ戻れる。別講義の投稿を混ぜない。
- C3: 005の一覧、タグ、詳細、ペンネーム/匿名、投稿・返信、画像添付と圧縮、小さいアイコンをアプリ内で利用できる操作見本として組み込む。全体掲示板にはサンプル、実講義は正しい空状態から始める。投稿/返信はアプリのセッション内で保持しタブ移動で黙って捨てない。
- C4: 常時見える位置に操作デモ/外部送信なし/終了時に消える旨を明記。実学生からの投稿や公開完了と誤認させない。公開サーバー/認証/運営・通報・削除・永続保存は既存005同様対象外。
- C5: 既存記事の下書き、予定/メモ/画像、テーマとナビゲーションを壊さない。Web経由ならネイティブbridgeを限定し、任意外部/file遷移やHTML実行を許可しない。画像処理中/入力中の遷移でもデータが別講義へ混ざらない。
- C6: build、既存記事/ナビ等に関係する回帰、board bridge/講義分離の検証、独立レビュー、Simulatorで一覧/詳細/講義往復/再起動後入口と狭幅を確認。本体bundleを更新、既存データを退避・照合。

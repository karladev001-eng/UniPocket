017 · 予定を先に読むUI / 仕様版2 · 承認待ち

目的・依頼の根拠最初に表示するものを「次の予定・今日の予定・時間割」に揃え、設定や正常時通知が占める面積を減らす。色と既存の5タブは継承する。

開く → 読む → 必要な操作だけ

ホームはコンパクトな次の予定と今日の3予定。週間は月〜金×1〜5コマ。その他は更新欄と小さな設定一覧。背景は自分の画像を実際のサムネイルで確認して選ぶ。

既存データから表示し、必要なときに詳細・編集・設定を開く。日/月表示、個人修正、PDF取込、自動更新の安全待機は継続する。

操作できるモックを開く ↗

準備：仕様・見本を確認 → 実装：表示と通知を修正 → 検証：独立レビューと本人限定配信。今回の成果物は準備段階。仕様・承認の正本は 017 / 仕様版2。

確定仕様

週間を月〜金×1〜5コマの表にする。空きコマも同じ位置で読む。同じ科目は曜日・週をまたいで同色。

390×700のアプリ領域で5コマと下部ナビが見える設計。320×640は横スクロール不要、5列を維持する。セル文字12px以上、セル操作72px高。正式名は詳細へ。色は見分け補助としてv2で提案。カテゴリ・重要度の意味は持たせず、有限の色は重複可。科目名・教室を併記し、次の予定は科目色を変えず枠とラベルで示す。

平日・土日と週移動を使い、重複・終日・コマ外も全件確認する。

土日は件数付きで切替。時間割の初回表示は週、セッション中は選んだ日/月表示を保持。ホームで特定日を選ぶと日表示へ、土日の「今日」は土日表示へ。コマ時刻は既存の8:40 / 10:20 / 12:45 / 14:25 / 16:05を再利用。時間変更や複数コマにまたがる予定は「その他の予定」に日時付きで残す。重複セルから全件選択。講義一覧・施設営業時間は表の後の折りたたみへ。

セルを押すと、省略しない正式名と日時・場所を確認して編集へ進む。

ホームは小さい日付行 → 次の予定カード → 今日の予定一覧の順に読む。

390×700で次の予定1件と今日の先頭3予定の題名（各2行まで）・時刻・教室を表示。次の予定も今日の一覧から抜かず、重複を許容する。件数が多い日はスクロール。正常時の保存済み・更新済みの大型通知を削減し、地図は固定リンク直上に置く。

今日の予定が空なら、次回カードの下に予定なしを表示する。

次の予定がないときは「次の予定はありません」と短く示し、その下に今日の一覧を表示する。操作モックの「次回なし」で確認できる。

時間割の操作は見出しと2行に収め、PDF取込を補助メニューへ置く。

未登録時はPDF取込の直接案内を表示。文字拡大時は切らずにスクロールできる。

その他は更新と小さな設定行。必要な操作のときに詳細を開く。

背景・テーマ / 時間割の表示 / 施設・リンク / ユーザー名 / データ。ユーザー名は既存表示名の確認・変更入口。未設定は「未設定」と表示する。アカウント作成・ログインは追加しない。内部実装説明は通常画面に出さず、診断buildは詳細情報へ。施設の目安・匿名ユーザーの復元制約は関連操作内で短く残す。

更新の確認・状態・新版のインストールを、その他の同じ欄へまとめる。

既存の安全待機・自動更新を維持。「編集後に更新します」はこの欄に表示。初回ホーム追加もその他へ。ホーム・時間割・記事・メモへ正常時の更新案内を常設しない。

保存失敗や競合、取込失敗は該当画面に残して、復帰操作を示す。

自分の画像も、6サンプルと同じサムネイルとチェックで選び直せる。

科目・教室は架空の表示例。6サンプルと4テーマは既存のものを継承。見本の「自分の画像」はローカルの風景イラスト。操作モックで手元の画像を選ぶと実画像で確認できる。製品ではアップロード直後・再起動後も同じ画像を表示し、サンプル切替後も自分の画像を残す。

選択前・読込中・エラーを区別し、エラーでは前の画像と選択を保つ。

ファイル入力が未選択でも保存済み画像は存在しうる。「変更」と「背景なし」を別の操作にする。

密度と例外表示を、390×700・320×640・PCで検証する。

  • 先頭3予定と平日5コマ、ナビの重なり、文字拡大を確認。
  • 長い正式名・土日・終日・重複・コマ外・複数コマ・時間変更・海を確認。
  • 背景の再読込、更新5状態、保存失敗と再試行を確認。
  • 日/月/編集/PDF/記事/メモと安全待機を回帰確認。
  • 独立レビュー後に本人限定Workerへ配信。実機未確認は区別する。
今回のモックはメモリ内で操作。再起動後の画像保持や実際の更新・保存・取込は本実装後の検証対象。

既存の予定データと更新制御を使い、表示だけを組み替える。

主な修正先はweb/src/main.tsとstyle.css。必要な表示用関数・テストを追加し、domain保存形式とupdate.tsの安全制御を維持。

PDF解析・予定編集規則・Swift・認証/DB・地図拡大画面は対象外。

  • 予定・個人修正・下書き・保存済み背景を維持し、データ消去・移送はしない。
  • 記事・メモの機能追加と、013地図拡大画面の再設計を含めない。
  • 012のホーム地図を固定リンク直上に置く契約を保持。

## 目的・根拠

2026-10-19、利用者がiPhoneでPDF取込成功を報告。5枚の実機画像とともに、週間がモックと異なる、説明が多い、自分の背景を画像で確認したい、大きい操作や設定に予定が押し出される、更新/インストールはその他へ集約したいと依頼。

最初に表示するものを「次の予定・今日の予定・時間割」に揃え、設定や正常時通知が占める面積を減らす。色と既存の5タブは継承する。

## 対象・入出力

- 対象: PWAのホーム/時間割/その他、共通の更新・保存表示、背景選択。既存データから描画し、セル選択や画像選択に応じて詳細/プレビューを表示する。
- 対象外: PDF解析規則、予定編集/繰返しの仕様変更、Swift、記事/メモ機能、認証/DB、013の地図拡大画面の再設計。ホームの地図を固定リンク直上に置く012の要件は保持。
- データ消去・移送なし。現在の予定/個人修正/下書き/背景を維持。設定の説明削減で保存失敗や個人データ保護の案内を失わせない。

## 提案仕様・受入条件

### S1 週間を曜日×コマの表へ（AC1–2）

- AC1: 既存003モックの月〜金5列×1〜5コマを基準に、空きコマと講義の位置が揃う週間表を表示。左にコマ番号/開始終了、セルに短い科目表示と教室。正式名は詳細で省略せず表示。短縮は見た目のみ、保存データを変えない。平日5列は320pxでもページ横スクロール不要、操作対象44px以上、セル文字12px以上。
- コマ時刻は既存の8:40–10:10 / 10:20–11:50 / 12:45–14:15 / 14:25–15:55 / 16:05–17:35を再利用。PDFの科目と個人予定の実際の日付・時刻を基準に表示する。
- 色は科目の見分け補助に限定し、同じ科目は曜日・週が変わっても同色。カテゴリ/重要度/履修状態の意味を持たせない。色数は有限で重複可、科目名・教室を必ず併記。「次の予定」や休講等はラベル/枠などでも示し、科目色を上書きしない。この色規則はv2での提案であり、v1の仮配色に意味があったとは扱わない。
- 時間割を最初に開くと週表示。起動中に利用者が日/月へ切り替えた場合はその選択を維持し、ホームの特定日への導線では日表示へ進める。土日は当日の列を含む切替を選ぶ。
- AC2: 平日/土日切替と週移動を設け、土日に予定があれば件数を見せる。終日・コマ外・時刻変更・複数コマにまたがる予定は表の直下の「その他の予定」に日時付きで全件表示し、消さない。コマに一致する重複予定は件数/複数件選択から全件を確認できる。講義セルを押すと既存の詳細/編集へ到達。登録講義一覧と施設営業時間は表の後の折りたたみへ移す。日・月表示と個人修正を保持。

### S2 開いた直後に予定を読む（AC3–4）

- AC3: ホームは小さい日付行→コンパクトな「次の予定」カード→「今日の予定」一覧の順。次の予定が今日の予定にも載る重複は利用者の希望に合わせて許容し、一覧から抜かない。次の予定には日付・時刻・正式名（表示は2行まで、詳細で全文）・教室を表示。次の予定1件と今日の先頭3予定（各題名2行まで/時刻/教室）、または予定なしと次回1件が390×700 CSS pxのアプリ表示領域でスクロールせず見える。次の予定がない場合も短い案内と今日一覧を表示する。件数が多い日は続きへスクロール可能。
- AC4: 時間割はコンパクトな見出し/＋予定/メニュー、日付と日週月切替の2行程度の操作にする。PDF取込を補助メニューに収める（未登録時には直接案内）。390×700で平日5コマの枠が下部ナビに隠れず初期画面に入る。320×640では最初の3コマを確認でき、残りへ通常スクロール。文字拡大時はスクロールを許容して文字を切らない。上部正常時の更新/保存済みの大型通知と英文見出しを除く。

### S3 その他を小さな設定一覧へ（AC5–6）

- AC5: 「その他」は更新欄と、背景・テーマ/時間割の表示/施設・リンク/ユーザー名/データをコンパクトな行に整理。「ユーザー名」は既存の表示名の確認・変更入口であり、アカウント作成/ログイン機能を追加しない。未設定時は「未設定」と表示。操作時に詳細を開く。IndexedDB/Swift移行/内部ビルド/全タブ処理など実装説明を通常画面から除く。診断用buildは「詳細情報」内に残す。施設情報が目安であること、匿名ユーザーの復元制約、保存失敗の対処など判断に必要な注意は関連操作の場所へ短く残す。
- AC6: 更新欄は「更新を確認」・最新/新版あり/確認中/失敗などの短い状態・新版待機時の「最新版をインストール」を基本とする。編集中待機は「編集後に更新します」と同欄に表示し、既存の安全待機/自動更新を保つ。ホーム/時間割/記事/メモへ更新成功やインストール案内を常設しない。PWA初回ホーム追加の案内もその他の中だけ。保存失敗/競合/取込失敗は該当画面で引き続き表示し、成功通知の削減と区別する。

### S4 自分の画像を見ながら選ぶ（AC7）

- AC7: 自分の画像が保存されている場合、6サンプルと同じ選択肢として画像サムネイル+選択チェックを表示。アップロード直後と再起動後に実画像が確認できる。サンプルへ切替後も自分の画像を選び直せる。「変更」「背景なし」の操作を添える。選択前/読込中/画像エラーも短く表示。エラー時は旧画像/選択を維持。ファイル入力の未選択表示と保存済み画像を混同しない。

### S5 保持と検証（AC8）

- AC8: iPhone相当390×700、320×640、PCで初期表示・長い講義名・複数予定・土日/終日/重複/コマ外・空・背景再読込・更新状態・保存失敗を検証する。日/月/予定編集/PDF取込/メモ・記事の主要経路、自動更新の編集中待機を回帰確認。独立レビュー後に本人限定環境へ配信し、実機未確認は区別する。

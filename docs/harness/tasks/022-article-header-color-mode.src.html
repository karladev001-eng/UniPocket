記事をすぐに。明るさは好みに。

今回の修正依頼自分の投稿と+登録のボタンの場所が違和感があります。また、ライトテーマとダークテーマを切り替えられるようにしてください記事を読むまでの項目が長いです。通報、再読み込み、Notionで開くであまり説明はいらないと思います。閲覧やブックマークの説明も不要です

説明を減らして、本文をすぐ下へ。

記事詳細の通常表示から閲覧/保存の定義や通信・公開確認の説明ボックスを外します。「通報 / 再読み込み / Notionで開く」を小さな操作行にまとめ、その直下に本文を置きます。

左に「記事」、右に「自分の投稿」と「＋ 登録」を横並びにします。検索や記事との間の空きを減らします。

「その他 → 背景・テーマ」でライト/ダークを選択。今の4色と背景画像を残して、一般アプリ全体の文字・カード・入力・ダイアログを合わせます。初期値はライトで、選択を端末に保存します。

対象は一般PWA。管理画面とNotion埋め込み内部の配色は含めません。保存互換→記事一覧/詳細・配色/選択UI→主要画面と旧データの検証の順に進める提案です。仕様正本022 / v2は承認待ちで、実装・配信はまだ行っていません。

説明を外し、小さな3操作の直下に本文を置く。（AC9–10）

入力・予定の表・エラー・フォーカスも同じ明暗で読める。

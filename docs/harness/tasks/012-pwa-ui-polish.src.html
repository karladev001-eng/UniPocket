静大ポケット · PWAの操作UI改善 / 仕様版2

今回のフィードバックタブのアイコンを修正してください。新しいメモを書くときにgoogle keepを参考にして項目を減らしてください。リストやファイルなど標準の見た目ではなく、他のUIにあわせてください。ホームからすぐにキャンパスマップを見れるようにしてください。匿名の記事からは同じ投稿者で絞り込む機能はなくていいです。右上の保存の意味が分からない。背景画像にサンプルを追加してください。

今回変えること

v2の差分：地図を固定リンクの直上へ移し、入口だけでなく地図そのものをプレビュー表示。背景は必要に応じて画像生成を利用する方針を追記しました。

見た目を揃え、普段使う操作を前へ。メモは本文を中心に、追加操作は小さなツールバーへ集めます。ホームの固定リンク直上には地図を表示し、保存は自動で行われることを伝えます。

対象はPWAの7点。既存メモ・画像・予定・匿名ユーザー・ブックマークを保持します。Swift版、認証方式、共有DB、Notion本文、配布方式の変更は含みません。

進め方：共通部品とメモ → ホーム・記事・背景 → 保存/更新/320px/キーボードの回帰確認。仕様正本は012 / v2。この画面は提案で、実装は承認待ちです。

固定リンクのすぐ上に地図を表示し、タブと保存状態を読み取りやすくする。

5タブは線幅・サイズの揃ったSVGアイコン＋名称。地図プレビューを「よく使うリンク」（固定リンク）の直上、固定したメモの後に常設します。ホーム上で地図が見え、地図または「拡大・検索」から既存マップを1操作で開けます。予定や固定リンクの有無で消しません。右上の手動保存はなくし、端末内保存の状態だけを表示します。

保存できないときだけ、入力を残して再試行を案内する。

「自動保存」は予定・メモなどの端末内データ。記事投稿の「登録」、編集フォームの確定、アプリ更新の「保存して更新」は意味が異なるため維持します。

新しいメモは本文だけですぐ書き始め、画像・リスト・色は必要なときに開く。

固定は右上のピン。画像・チェック項目・色・その他を下部に集め、削除はその他へ。タイトル専用欄は増やさず、従来の本文・画像・色・チェック・固定を維持します。「完了」で保存を確認して閉じ、失敗時は入力を残します。空のまま閉じた新規メモは残しません。

追加機能を開いた状態と、保存失敗も分かる。

選択・ファイル追加を共通の見た目に揃え、匿名投稿者のリンクを外す。

カテゴリ・講義・色・テーマなど、アプリ内の選択一覧を角丸・配色・余白の揃ったメニューへ。画像/PDF/背景の追加は専用ボタンと選択済み表示へ。OSが開くファイル選択ダイアログ自体は標準のままです。表示名未設定の「匿名ユーザー」は一覧/詳細とも非リンクにし、表示名を設定した投稿者の絞込は維持します。

キーボードと小さい画面でも選択できる。

選択メニューは上下キー・Enter・Escape・フォーカス復帰に対応。320px幅で画面外へはみ出さず、選択中と操作対象が見分けられることを確認します。

背景は6つのサンプルからすぐ選べ、自分の画像にも戻せる。

森・海・空・夕暮れ・紙・幾何のオリジナルSVG背景を同梱する提案です。画像素材が必要になった場合は、ユーザーのコメントに沿ってimagegenスキルで生成し、同梱用に最適化します。外部サイトへの通信なしで表示し、選択を再起動後も保持。現在の背景画像も保持し、サンプル/自分の画像/背景なしを切り替えられます。

既存データとアプリの基盤はそのまま引き継ぐ。

メモ・画像・予定・匿名ユーザー・ブックマークを保持。Swift版、認証方式、共有DB、Notion本文と配布方式は今回の変更対象外です。

受入条件

  1. AC1 全5タブを同じSVGアイコン体系へ置換。名称・選択状態・44px以上の操作領域。
  2. AC2 新規メモの初期入力は本文のみ。追加機能と既存データを維持。保存失敗・空メモ・IMEを確認。
  3. AC3 全対象のselect/file表示がアプリ内で統一。キーボード操作と選択状態・ファイル名/画像プレビューを確認。
  4. AC4 ホームの固定リンク直上に地図を表示し、1操作で既存の拡大・検索画面を開き、戻れる。
  5. AC5 匿名ユーザーの投稿者絞込リンクを一覧/詳細から除去。表示名ありのID絞込は保持。
  6. AC6 常設手動保存をなくし、端末内自動保存の待機/成功/失敗を正しく表示。
  7. AC7 6つのサンプル背景・自分の画像・背景なしを選択し、再読込/オフライン/更新後に保持。
  8. AC8：320px/PC、メモ・画像・PDF・ブックマーク・2タブ更新の回帰確認。Swift変更なし。

実装前に必須の質問はありません。「匿名」は表示名未設定を指す案です。背景は写真ではなく、画面に馴染む6種類のイラスト/模様を提案しています。変更希望は該当箇所へコメントできます。

v2の変更

「時間割を見る」は13px程度の文字と小さな矢印に整理。44pxの操作領域は保ち、塗りや枠で大きく見せません。ホームの＋も控えめにします。

次／いま、今日一覧、共通詳細の場所は独立操作へ。ホーム地図まで移動し、登録教室名と対応建物の位置を表示。未対応・複数候補ではピンを推測しません。

確定した方向と、今回の提案仕様

以下の具体値は仕様版2の提案です。コメント・回答と、本実装への承認を分けて扱います。

ホームは「時間割を見る」→次／いまの予定→今日の予定の順にする。（AC1–2）

時刻を強く見せ、今日一覧には次の予定も残す。場所は別操作にする。

終日は次回カードへ入れず今日一覧へ。題名は2行、場所を表示。重複も一覧から全件を確認する。ホームの＋は今日から開始する。

5タブを維持し、時間割をホームと予定表から開ける。

下部：ホーム／予定表／記事／メモ／その他。旧 #timetable も時間割へ。ホーム地図は固定リンク直上、営業時間・固定メモも維持する。更新や正常保存の案内をホームへ戻さない。

場所をタップすると、ホームの既存地図へ移動して対応建物を示す。（AC2・7）

ホームの次／いまカード・今日一覧・共通詳細に、本文とは別の場所操作を置く。buttonの入れ子は作らない。タップで詳細を閉じ、ホームの固定リンク直上にある地図へスクロールし、見出しへフォーカス。reduced-motionでは滑らかな移動を使わない。

不明・複数候補では勝手にピンを置かず、元の場所名と検索を残す。

未設定・オンラインは地図リンクなし。登録教室でも座標は建物だけなので「建物の位置」と明示する。別の場所を選ぶたび古いピンを消す。外部地図・GPS・地図再設計は対象外。

講義専用の時間割は、017の月〜金×1〜5コマを引き継ぐ。（AC3）

個人予定・大学行事は予定表へ残し、コマへ混ぜない。

取消の扱い・取消管理は既存仕様を維持。空欄は空きコマ、空週は短い案内、講義未登録はPDF取込へ。今回の＋は個人予定追加へ進み、講義を手入力する新機能は作らない。

コマ外・時刻変更・終日・日またぎの講義を日時付きで全件残す。

予定表にも同じ実日時で表示。週をまたぐ講義は、交差する各週で確認できる。1限→2限など正規の時刻へ変更した場合は移動先コマへ載せる。

予定表は実時間の長さと重なりを見せ、日／3日／週／月を切り替える。（AC4–5）

表示単位で移動し、手で選んだ表示を起動中に保持する。

初回は390pxで3日、320pxで日、PCで週を提案。リサイズで選択をリセットしない。今日は当日に戻る。00:00–24:00へ縦スクロール、今日なら現在時刻付近、別日なら最初の予定、空なら表示開始設定時刻へ。週表示は日列を保つ内部横スクロールを許す。

重複・5分・終日・日またぎ・空の状態でも、予定を落とさず詳細へ進める。

Tokyoを内部基準に統一。開始を含み終了を含まない。00:00終了を翌日へ余分に表示しない。現在時刻線は今日の列だけ。日付見出し・時刻軸を保ち、長題名の全文・実日時・場所は詳細へ。

月表示は全日に届き、日付から時間軸、件数から全件一覧を開く。

月末・翌月・年末も月単位で移動。日付を選ぶと、その日の日表示へ切り替える。

同じ予定IDと既存の個人修正を使い、ホーム・時間割・予定表へ反映する。（AC6–7）

予定タップから共通詳細へ進み、既存の編集範囲と取消を継承する。

場所は本文と別操作。カレンダー・時間割の詳細からも、同じホーム地図へ移動する。不明なkindやcourseIDを失ったpreserved予定も予定表から落とさない。科目色は見分けの補助、種類は文字でも示す。モックは同一id編集の反映を示すだけで、取消や一括修正の実処理は既存機能の検証へ引き継ぐ。

個人予定の追加は選択日・空き時間から開始し、失敗しても入力を残す。

取込プレビュー、個人修正競合、編集中の自動更新待機、保存／閉じるの既存動作を保持。色変更・ドラッグなど追加範囲外の操作は見せない。

狭幅・例外と既存機能の回帰を検証してから実装を配信する。（AC8）

390×700で次／いま1件＋今日先頭3件、時間割5コマをナビ上に配置。320×640では通常スクロールを許し先頭3コマを確保、時間割の平日5列はページ横スクロールなし。セル12px以上、操作44px以上。

今回は仕様とモックの静的・表示検証まで。本実装の成功とは扱わない。

既存の予定・コマ判定を使い、時間軸の表示計算だけを追加する。

保存形式の変更を避け、既存CampusEventを表示の基準にする。

courseID/originalsはdomain.ts:164/172、PDF種別はpdf-parser.ts:185/206。calendar-presentation.ts（提案）で日分割・重なり・描画位置を計算し、既存の週間コマ関数を再利用する。SDKや新しい依存は現時点不要。地図は既存map.tsの完全一致・解決状態、map-catalog.jsonの建物座標と別名、main.ts:235のホーム地図と:1274のopenMapを再利用。013の地図再設計は実装しない。

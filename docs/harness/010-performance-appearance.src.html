自分らしい背景へ。

起動と表示を整え、テーマ設定を「その他」にまとめます。

5つのタブと今までのデータを維持。初期背景は無地のまま、好きな画像を端末内で設定できます。

順序：基準計測 → 読込・表示改善 → テーマ・背景 → 比較計測と回帰確認。

実装前の提案です。速度は未計測で、改善幅は実装後に報告します。

起動時に重い読み込みを待たせず、データを安全に表示する。

現在は画面スレッドで保存データを読み込みます。非同期化し、読み込みが終わるまでは編集を開始しません。

カレンダーと画像の処理を整理し、切替とスクロールを軽くする。

カレンダーの重複取得と予定の再計算を減らし、地図と画像は必要な時に準備します。保持済みWebViewと入力途中の内容を守ります。

表示用の画像を軽くし、保存処理の順序と失敗時の保護を守る。

サムネイルは非同期デコードと上限付きキャッシュへ。メモの原画像は変更しません。

テーマは「その他 → テーマ・背景」にまとめる。

各画面のパレットを外し、4色の配色と現在の選択を引き継ぎます。

無地をデフォルトに、好きな画像をプレビューして設定する。

写真の上でも、授業とメモを読みやすくする。

5タブ共通の背景に適用。カード・記事本文・編集面は読みやすい面を維持し、地図や画像ビューアの内容は変えません。

取消や失敗で、これまでの背景を失わない。

JPEG / PNG / HEICの静止画。最大40MiB・各辺20,000px。表示用は長辺2,560px以下にして端末内保存。原画像は変更しません。

速さは同じ環境で比較し、機能と読みやすさも確認する。

起動・各タブ初回/再訪を各10回。初回描画とデータ反映完了を別計測し、中央値と遅い側を比較します。通常/大量データ、375pt、文字拡大、4色、明暗の背景、保存失敗、再起動まで確認します。

Core・記事・掲示板回帰、Simulatorビルド、独立レビュー。実機の速度は実測なしに保証しません。

今回の範囲と維持するもの。

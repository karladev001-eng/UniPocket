仕様・画面の提案

項目を開くと、画面 → 振る舞い → 既存コードの順に読めます。すべて初期状態は閉じています。画面例の日付は2026年10月7日、外部予定・メモ文は架空です。

ホームを開くと、今日・次の授業・すぐ使う情報が分かる。

7日間の時間割・現在線・営業時間を、1画面で見渡す。

色だけに頼らず、時刻と施設名を文字でも示す。

  • 現在線は今日の列だけ。毎分・画面復帰時に更新。別の日に架空の現在線を描かない。
  • 次の授業までの残り時間、授業中は終了までの時間を表示。対象なしは「今日の授業は終了」。
  • 営業時間は各日の右端に2本の淡い帯。凡例を下に集約し、施設名と正確な時刻はタップで表示。表示施設とON/OFFを変更できる。
  • 日付別例外を優先し、休業日には帯を描かない。未確認は「通常期の目安」。昼夜の間は塗らない。
  • 画像例は12:10固定。実装では現在時刻・選択日から算出する。
週の一覧は標準文字サイズで375×667pt以上を基準に設計。大きな文字では無理に縮小せず、日別一覧・詳細で読みやすさを保ちます。時間軸は08:00–19:00、2時間ごとの目盛り＋19:00終端。終日・時間外を件数で示し、タップで確認できます。

週では短く、タップした予定は全文・開始終了・教室まで読める。

  • 週の枠には上から短縮名・開始・終了。教室と正式名は選択カード・詳細へ。
  • 短い予定や重複はマーカーと件数。日をタップするとその日の全件一覧。
  • 終日・08–19時の範囲外は日付別件数をまとめる。タップで日表示へ。予定を黙って除外しない。
  • 施設の帯を選ぶと、施設名・昼夜の時刻・確認日・例外を表示。

未取り込みや授業がない日も、次の操作を示す。

授業なしと、取得済みの予定だけを示す状態を分ける。

現ホームは大学予定のみ。外部予定と共通化する部分を見分ける。

PDF2点から授業を作り、曖昧な項目と再取り込みの差分を確認する。

休講・日時・教室の個人修正を元データと分けて保存する。

行事予定の授業日を使い、日時未定や試験候補は確定しない。

既存の端末内解析を基盤にし、確認と修正の仕組みを加える。

Outlookの既存予定を、アプリ内の授業と一緒に表示する。

Q1は表示のみ。アプリから外部予定を書き換えない。

  • 端末のカレンダーから選択したものだけを読み、週・月・日・ホームに表示。
  • PDF取り込みや休講の修正はアプリ内で完結。書出しボタン、差分反映、同期キューを初回から外す。
  • 既存初期版の書出し経路を画面と処理の両方で無効にする。過去に書き出した予定があっても自動削除しない。
  • 所有マーカーで識別できる旧書出しは表示上の重複を抑止。タイトルや時刻の一致だけで別予定を隠さない。

食堂・生協の通常時間と当日の例外を、通信なしでも見られる。

個人の臨時変更と未確認情報を、通常の営業時間と区別する。

現在は自由文の時間を保存している。曜日と日付別例外への変更は提案。

画像付きメモを保存し、よく見る画像をホームから開く。

画像をメモに添付して、ホームへ固定・拡大・固定解除する。

リンクはお気に入りと並べ替え。画像はホームの固定カードに分ける。

本文と画像を端末に保存し、失敗時は保存済みの内容を守る。

  • 本文の自動保存と画像の追加状態を別々に表示。新しい画像が失敗しても本文・既存画像を残す。
  • 画像は管理IDで参照し、元ファイルへの一時URLに依存しない。画像ファイル保存後に参照を確定する。
  • ホーム固定はメモへの参照。固定解除で原本を消さず、メモ削除時は固定も外す。
  • Q6は端末保存のみ。アプリ独自のバックアップ・復元・iCloud同期は初回に含めない。

共通設計は、オフラインの保存データを中心にまとめる。

旧データを退避してから移行し、失敗したら旧版を残す。

初回の対象外を、回答に合わせて絞る。

  • Outlookへの書出し・変更・削除・常時背景同期・直接Microsoft接続。
  • 前期や未知形式のPDF、OCR、外部AIへのPDF送信。
  • 施設の公式情報の自動取得、アプリ独自のバックアップ・復元・iCloud同期。
  • 通知・ウィジェット・一般公開・App Store公開。
  • 画像の自動地図取得、OCR、動画、直接撮影は追加案には含めない。写真・画像ファイルの選択と拡大を提案。

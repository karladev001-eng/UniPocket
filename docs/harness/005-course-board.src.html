講義掲示板のモックを開く ↗
本人の依頼次は講義詳細からその講義の掲示板に移動できるように、掲示板の画面も同じ雰囲気でモックを作って下さい。画像も載せられるようにしたいです。返信にも載せられるようにして、画像はアプリ内で自動的に圧縮されるようにしましょう。LineやXのような感じで投稿や返信ができるようにしたい。ボタンを小さくして、画像や送信などはアイコンだけでいいです。

記事を読む画面へ

「記事」タブから記事一覧・詳細のモックへ移動できます。ホーム講義詳細の関連する記事も、講義に対応した一覧へ進めます。

記事モックを開く · 006の仕様と画面案

講義詳細 → 講義の掲示板 → 投稿と返信を読む → ペンネームまたは匿名で投稿。キャンパス全体と講義ごとの公開掲示板を行き来できます。

ホーム・時間割と同じ4テーマ、余白、丸いカードを使用。本文・投稿者・反応数は架空のサンプルです。入力や選んだ画像はこのページ内の表示にだけ反映し、外部へ送信しません。

仕様と画面案

講義詳細から同じ講義の掲示板へ移動し、テーマも引き継ぐ。

ホームと時間割の講義IDを対応させます。全9科目を区別し、戻り先はアプリ内のホームか時間割。デモでホーム未掲載の講義へ切り替えた場合は時間割の講義詳細へ戻します。未知のIDは別の講義として表示しません。

公開掲示板の投稿を、講義やタグから探す。

タグ・タイトル・本文抜粋・投稿者・返信数・いいね・閲覧数から内容を把握。履修者限定やサークル内部の連絡機能は設けません。

投稿を開き、返信やいいねで情報交換する。

返信・いいねはページ内だけに反映。別の講義に投稿が混ざらないよう分けます。大学公式の連絡とは区別します。

返信先を見ながら、文章と画像をその場で送る。

文章だけ・画像だけ・両方に対応。ペンネーム/匿名を選べ、Enterは改行、送信ボタンで送ります。入力途中の内容は投稿ごとに保持。画像処理中は送信を止めます。

ペンネームや匿名で、文章と画像を投稿する。

本文や画像を中心に入力。タイトルは任意です。文章または画像があることと文字数を確認し、匿名時はペンネームを投稿に表示しません。閉じた下書きはページ内で保持します。

画像を選び、確かめてから投稿する。

最大4枚、JPEG・PNG・WebP、入力1枚20MB・2,400万画素までの提案。添付を個別に削除でき、下書きにも残します。読み込み中や形式・容量・枚数の不備がある場合は説明を表示し、既存の文章・画像を保ちます。

投稿の画像を大きく見て、元の投稿へ戻る。

一覧と投稿詳細に画像を表示。拡大表示は閉じる操作とEscapeに対応。画像は端末内のデモで、実際の公開・保存はしません。返信の画像も同じように拡大できます。

選んだ画像はアプリ内で自動的に軽くする。

縦横比を保って長辺2048pxまで縮小し、WebPで再エンコード。透過対応のPNGへフォールバックできます。縮小不要で元が小さければ原本を採用し、圧縮不要と表示。数値は実際の処理結果を使い、見本値は区別します。実ブラウザーの圧縮品質は未検証です。

同じ雰囲気で、キャンパス全体と講義の掲示板を使う。

4テーマ、名前付きの操作、フォーカス表示、狭幅を想定した配置を用意。実ブラウザー描画・実DOM操作は未検証です。

画像や送信は、小さいアイコンで操作する。

見た目は32〜36pxの背景と18pxのアイコン、押せる範囲は44px。操作名は読み上げラベルとツールチップで保持。処理中もアイコンを保ち、送信不可の状態を伝えます。

今回は操作モック。実際の投稿公開・アカウント・掲示板作成は含めない。

講義と投稿は表示例です。投稿・返信・下書き・選択画像は永続保存されません。実配信・保存や運営機能は、本実装の前に別途設計します。

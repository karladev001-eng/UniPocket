今回は固定サンプルによる操作見本です。確認日・版も表示例で、実際の公式日程を確認・公開したとは扱いません。PDF解析・本登録・大学との同期は行いません。

仕様と画面案

学生は履修登録PDFを用意し、アプリ側が浜松キャンパスの日程を提供する。

共通日程の大学・キャンパス・年度・日付・扱いは読取り専用。対象年度、確認日/版の見本、公式資料へのリンクを表示する。

履修PDFの候補を確認・修正し、対象キャンパスと年度を合わせる。

曜日・時限はカレンダーのマスから指定。年度不一致は学生側の候補訂正か、正しい履修PDFのサンプル再選択で解消する。アプリの日程を変更して合わせない。

確認済み日程の祝日・休業・授業例外を適用し、登録する回を確認する。

科目は残し該当日だけ除外。重なる理由を二重減算しない。臨時休講や個別振替は自分の時間割で調整し、共通日程の更新で個人調整を無断上書きしない。

共通日程が未確認なら確定を止め、アプリ側の確認済み日程を待つ。

本人確認のチェックだけでは未確認日程を回避できない。年間PDFの提出も求めない。確認済みの表示例へ切替可能。製品では日程を端末へ保存してオフラインで利用する想定。モックはページ内だけで、既存ホーム/時間割の仮データを実更新しない。

実公式日程の公開・実PDF解析・製品保存は含めない。

浜松キャンパス版に限定。全国展開や未対応大学での年間PDF取込みは将来の検討項目。
